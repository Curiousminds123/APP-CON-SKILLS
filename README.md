# TeacherAI - Plataforma Educativa

Plataforma de herramientas educativas impulsadas por inteligencia artificial para docentes.

## Descripción

TeacherAI es una solución integral para crear y gestionar materiales educativos de forma automatizada y personalizada.

## Capacidades Principales

- Generación automática de cursos estructurados
- Creación de ejercicios y evaluaciones interactivas
- Herramientas de apoyo pedagógico
- Integración con sistemas de gestión de aprendizaje (LMS)
- Accesibilidad universal integrada

## Instalación

```bash
git clone <repositorio>
cd APP-CON-SKILLS
npm install
```

## Uso Local

```bash
npm start
```

Luego abre `index.html` en tu navegador.

## 🎯 Cómo Funciona

### 3 Pasos Simples

```
1️⃣  Elige herramienta → Curso, Juego, Evaluación, etc.
2️⃣  Responde preguntas → Sistema entiende tu contexto
3️⃣  Descarga todo → HTML, PDF, SCORM listos para usar
```

### Ejemplo: Crear un Curso Completo

```
Usuario: "Quiero un curso sobre Revolución Francesa"
         Nivel: ESO, Duración: 4 semanas, 30 min/día

Sistema:
  ✓ 8 unidades temáticas
  ✓ 30+ lecciones personalizadas
  ✓ 4 bloques por lección (Teoría, Ejemplo, Actividad, Test)
  ✓ Evaluación final de 10 preguntas
  ✓ Rúbrica de desempeño automática
  ✓ 2 proyectos finales

Salida: 
  📄 Aula virtual HTML (responsive)
  📄 PDF Guía docente
  📄 PDF Guía estudiante  
  📦 Paquete SCORM para Moodle/Canvas
```

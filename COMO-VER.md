## Opción 2: Abrir localmente en tu navegador

### En Windows:

1. Clona el repositorio:
```bash
git clone https://github.com/Curiousminds123/APP-CON-SKILLS.git
cd APP-CON-SKILLS
```

2. Abre directamente en navegador:
   - Haz doble clic en `index.html`
   - O arrastra a tu navegador favorito

3. ¡Verás la landing page completa! 🎉

---

## Opción 3: Con servidor local (Para desarrollo)

### Python:
```bash
cd APP-CON-SKILLS
python -m http.server 8000
# Luego abre http://localhost:8000
```

### Node.js:
```bash
npm install -g http-server
cd APP-CON-SKILLS
http-server
```
